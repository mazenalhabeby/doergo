🔁 People who JOIN (not create) — skip the space step
Joining an existing org (code or invitation) does NOT create a space. Joiners land straight in the org and work inside the spaces the admin already set up — so the “first space” step only ever shows for the person creating the org.
Safety net: if an org ever has zero spaces (last one deleted), creating a task shows “Create a space first” instead of failing — never an auto-“General”.
