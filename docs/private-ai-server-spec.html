Private AI Server — Build Specification

Fully on-premise AI · no data leaves your servers · runs a 32B model (covers all planned AI features)

Prepared 2026-07-28 · Colocation-ready

Why 32B and not 96B: a 96B model needs far more GPU hardware. A 32B model handles every planned feature — because the "intelligence" comes from your data + code (analytics, ranking, retrieval), while the model does the language (summarise, extract, draft, explain). You can upgrade the GPU later with no software changes.

What this machine runs & enables

Models
  • 32B instruct model (e.g. Qwen2.5-32B) — multilingual EN/DE/ES
  • 14B model for high-volume cheap tasks
  • Embeddings model (bge-m3) for semantic search
  • Whisper for voice → text (field techs)
Features it powers
  • Org analyst digests · smart dispatch suggestions
  • Service-report auto-draft · NL → task / report / analytics
  • Member coach · role-aware assistant · risk alerts
  • Semantic search across jobs / assets / customers

Notes

  • Software (no licence cost): Ubuntu + vLLM or Ollama (private, OpenAI-compatible endpoint) + pgvector on your existing PostgreSQL. Nothing leaves your network.
  • Upgrade path: swap to bigger GPUs later (RTX 6000 Ada / A100 / H100) with zero software changes — the model sits behind an interface.
  • Longevity: used consumer 3090s aren't ECC/datacenter-grade, but run reliably for years with good cooling.
  • Colocation: a tower or 4U case in an EU datacenter keeps it GDPR-clean and always-on.
