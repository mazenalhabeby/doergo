Messages, with motion

A working copy of the web Messages page for review. Everything moves the way it would in the app: open a conversation, send a message, search, open a group, start one. The list below replays each animation on its own.

The motion, one by one

Each is short (0.2–0.45 s), springs only where something arrives, and is switched off for anyone who asks their system for reduced motion.

Icons: four special treatments

Each starts from professionally drawn shapes (Solar, Hugeicons — free for commercial use) and stays in one colour family, so the same icons work on the web and in the phone app. What makes them special is the treatment and the motion. Hover any icon; "Use in the mockup" switches the page above.
