No-shows that sort themselves out

Right now every missed shift lands as "Escalated" and sits there; the only choice is "Excuse". In the demo that is 85 rows, mostly the same three people on the same shift. Here the system settles what it can prove, asks a leader one clear question about the rest, and spots the pattern.

1 · Before anyone is asked

The system settles what it can prove

These checks run when the shift is missed and again before it reaches a leader. Each one closes the no-show with the reason written on it, so nobody has to excuse anything by hand.

2 · In Approvals

One question for the leader, with an answer that closes it

Only what is left reaches Approvals. The leader sees what the system already checked and picks one of three outcomes. "Absent" is new: today there is no way to say "this really was a missed day", so rows stay open forever.

3 · The pattern

Three days the same way becomes one item, not three

When the same person misses the same shift again and again, Approvals shows one grouped item instead of one per day. A long run usually means the rota is wrong, so fixing it is offered first, and one answer closes every day in the group.

Lisa Adler · 4 missed shifts in a row
Main Office · 11:11–19:11 · Oct 9–14
WThFSaMTW
LikelyLisa has not clocked in at Main Office since Oct 8 but works at Service Center every day. The shift is probably on the wrong workspace.
4 · Attendance → No-shows

The tab becomes a record, by person

No buttons and no "waiting" banner. One row per person for the period, with how each missed day ended. Open rows link to Approvals; Reopen stays on a decided day for a leader who changes their mind.
