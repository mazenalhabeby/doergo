④The rules
THE RULES
not a widgetIt is chrome, pinned under the header. Never in the registry.It cannot be moved, hidden or reordered, because it is not one of the member’s choices — it is the app asking them for something. ⑨ Documents is still a widget and still theirs.
one lineThe line changes instead of multiplying.Already the rule the old reminder card argued for, and it is right. One thing named, the rest as a count. 54pt, or 68pt when it blocks work — and that one earns the second line.
absent, not emptyNo outstanding item → the strip is not rendered.No zero state, no “You are all caught up”, no collapsed bar. The header sits straight on the first widget, exactly as it does today.
no dismissThere is no ✕.It is a state, not a message. It goes when the work is done. A dismiss would let a member hide the thing stopping their own jobs arriving.
one tapOne item → straight to it. More than one → the list.Never a dead end. The strip is the shortest path to finishing the thing, not an announcement about it.
tonecrit only when blocksWork. warn for the rest. Expiring is neither.Red must keep meaning “this is stopping you”. A licence with twelve days left is a mention, so it is ink on tile with no tint at all.
say the thing“Upload your ID card”, never “1 document outstanding”.A member should be able to act without opening anything. Name the document and, when it was sent back, quote the reason — it is already on the wire.
motionIt slides in once, on arrival. It never animates again.Nothing about it should be attention-seeking after the first second. It is a fact on the page, not a notification.
