⑥What is on screen now
WHAT IS ON SCREEN NOW
✕The whole screen is blue. Navy ground, indigo blob, and a green→blue gradient button.Blue appears nowhere else in this app. The sign-in screen is the first thing anyone sees, and right now it belongs to a different product than the one behind it.
✕“Access your dashboard and manage operations.”A field member has no dashboard and manages nothing. They clock in and pick up jobs. It is B2B website copy on a workforce app.
✕“Enterprise protected · Secure” with a padlock and a shield.Two badges that change nobody's decision — and unearned trust marks are exactly what a phishing page puts there. Being secure is not a feature to claim; it is a thing to be.
✕The invitation code is four taps away.Create one → register → choose path → use invitation. Most people opening this app for the first time were sent a code by their employer, and that is the one route the screen does not offer.
✕Three escape hatches, none of them the common one.“Forgot password?”, “Create one”, “Contact support” — and the last two sit 400pt apart at the bottom of an otherwise empty screen.
✕Icon boxes with dividers inside every field.A bordered square, a 1px rule, then the input. Three borders to say “type here”. Amazen fields are sunken, with the label above them.
✕“Create one” promises more than it does.Registering does not get you into a workspace — it lands on choose-path, where you still have to start a company, ask to join one, or enter a code.
⑦The rules
THE RULES
one groundThe home gradient, from the first screen.#0c4339 → #040507, the same one behind the home screen. Signing in should feel like arriving somewhere you already were, not passing through a different app.
the code firstThe most common first run gets a route on the sign-in screen.A row under the button, not a link at the bottom of a menu. Ten seconds from a code to a workspace.
say the job“to clock in, pick up your jobs and see your hours”.Three things the person opening it actually does. If the subtitle could sit on any SaaS login, it is doing no work.
no badgesNo padlocks, no shields, no “Enterprise”.Nobody decided anything because of them, and claiming security is a phishing tell. What earns trust here is the employer's name appearing when the code is entered.
checks livePassword rules tick as you type, in jade.Not a red wall after the button. Three short checks — 8 characters · a number · a capital — and the button stays live the whole time.
fields are sunkenLabel above, one sunken box, no icon and no divider.The same field as every sheet in the app. Show is a word, not an eye.
name the companyThe moment a code is valid, say whose it is.“HBC Group · Main Office · invited by Anna Müller as a team member.” That is the confirmation that matters, and it is the only trust mark on the screen that is earned.
honest register“Then you can start a company, join one, or use a code.”It says what happens next, so choose-path is an expected step rather than a surprise wall.
