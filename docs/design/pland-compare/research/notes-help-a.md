## 1. Dashboard basics, navigation, lists (#111560, #211761, #234980, #142237)

- Login: `cloud.pland.app` (both Dashboard and App use the credentials). Landing page after login = employee overview [Mitarbeiterübersicht]. (#111560)
- **Implementation area [Implementierungsbereich]**: click the PlanD logo top-left → shows which employees already have Einsätze planned, which have logged into the app, and onboarding status. (#111560)
- **Notifications** (bell, top right): who logged into the app, which documentations [Dokumentationen] were created, whether Arbeitsscheine were signed (#111560); also when an employee ended an Einsatz with a comment or photo documentation (#176616); birthday push in Dashboard if Geburtsdatum set (#197465).
- **Global search [Globale Suche]** Dashboard shortcut Ctrl+S / Cmd+S. Searches Kunden, Objekte, Mitarbeiter, Aufträge, Rechnungen, Dokumente. Icons: customer = one house, object = two houses. (#111560)
  - Manager-App: global search **replaced the old "Objektmappe"** in the app navigation; tabs Mitarbeiter, Kontakte, Kunden, Objekte, Dokumente. Material orders and tickets searched with `#` + number (e.g. `#1234`) — the `#` is mandatory. Rechtegruppe option **"Objektleiterfilter aktivieren"** restricts results to employees/objects/contacts/customers linked to the user's own assigned objects. (#211761)
- **Mass change [Massenänderung]**: tick checkboxes in any table → options appear on top. Employees example: Mitarbeitergruppen, Lohnarten, Status (e.g. "Passiv"), Rechtegruppen. (#111560) Aufträge: some fields (e.g. Startdatum, Rechnungsvorlage) mass-editable; **Abrechnungsart, Abrechnungsintervall, Abrechnungstag NOT mass-editable** — workaround: open one Auftrag and use the next/previous arrows top right. (#572389)
- **Column settings [Spalteneinstellungen]**: top-right of any table; pick columns, reorder via six-dot handle; persisted per user across logouts. Applies to employee, object, customer, Auftrag lists, invoices, tasks. (#111560, #234980)
- **Quick-Actions** (Einsatzplaner): small square boxes on hover over Einsätze, employee names, or days. Always: duplicate, release (for payroll) [freigeben], delete Einsätze. Combine with filters. All ticked Einsätze move together when dragging. Hover employee name → tick all that employee's Einsätze (e.g. before setting employee passive). Hover a date → tick all Einsätze of that day (e.g. holiday re-planning/deletion). (#142237) Also Quick Action "Arbeitsschein erstellen" (#747838), assign / add team members (#742934).

## 2. Employees [Mitarbeiter] (data fields seen in half A)

- Employee profile tabs mentioned: **Vertrag** (Wochenstunden, Arbeitstage e.g. Mo–Fr, jährlicher Urlaubsanspruch, Abwesenheitsfortzahlung pro Tag [daily continued-pay rate], Fahrzeiterfassung allowed toggle, Vertragsstart/-ende), **Abwesenheiten** (entitlement, available, taken; "Urlaubsanspruch anpassen" add/subtract days), **Lohnzeit** (payroll times per Einsatz incl. travel), **Logbuch** (book icon top right, last tab "Aufgaben"). (#747887, #111569, #112719, #747555)
- Payroll-relevant: Stundenlohn, Lohnart (e.g. "Leistung"), Wochenstunden, Mitarbeiternummer (must equal personnel number in payroll system). (#747902)
- Filtering for payroll export: Mitarbeitergruppen (e.g. Glasreiniger, Unterhaltsreiniger), Anstellungsverhältnis, Mitarbeiter-Tags. (#747902)
- Access rights at creation: only employees with access right **Administrator or Objektleiter** appear as selectable Objektleiter on an Objekt. (#111563) Dashboard users = Objektleiter, Innendienst, Admin (#742597).
- App credentials delivered by **SMS**. (#202851)
- Employee status Aktiv/Passiv (mass change). (#111560)
- **Import fields** (#197465): Personalnummer (agree with payroll office; used in payroll export), Anrede, Nachname, Vorname, Adresse (country written out "Deutschland", not "DE"), Geburtsdatum `TT.MM.JJJJ`, Telefon with country code (+49/+43), Beschäftigung (free category e.g. Gebäudereiniger, Innendienst, Büro, Objektleiter), E-Mail, bevorzugte Sprache (for internal communication; the app language follows the phone's system language, NOT this field), Wochenstunden — **whole numbers only, decimals cannot be imported**.

## 3. Customers [Kunden] & Objects/Sites [Objekte] (#111563, #742597, #197465, #112401)

- Navigation: sidebar "Objekte" → sub-item "Kunden". Button "Kunden erstellen". (#111563, #742597)
- Customer statuses: **Aktiv**, **Interessent** (prospect), **Passiv**. (#742597)
- Customer fields: Kundenname, Kundennummer (recommended = Debitorennummer from FiBu), Adresse (= billing address), Adresszusatz. Option **"Objekt automatisch erstellen"** creates an Objekt with the same address. Customer address not mandatory; **object address mandatory** (for GPS match at time capture). (#111563, #742597)
- **Kontakte** (recommended over generic contact fields): first/last name, e-mail, phone per contact; linkable to individual Objekte; optionally shown in the app on the Einsatz (e.g. Hausmeister). (#742597) Import: Anrede, Vorname, Nachname, E-Mail, Telefon, Mobil, Kundennummer and/or Objektnummer (contact can belong to customer, object, or both), Position, Kommentar. (#197465)
- Tab **Vertrag**: Vertragsstart/-ende, status. ⚠️ Setting a **Vertragsende sets all linked Objekte, Aufträge and Einsätze to Passiv automatically.** (#742597) Objekt also has Vertrag → Vertragsende, and "Sonstiges" (e.g. door access code). (#111563)
- Tab **Dokumente**: ⚠️ all Dashboard users (Objektleiter, Innendienst, Admin) see customer documents; no restriction. Workaround: post as Logbuch message with attachment (restrictable, e.g. admins only) → found in Logbuch under "Dateien". (#742597)
- Tab **Rechnungswesen** (customer): e-mail for invoice dispatch; **Rechnungsempfänger** (extra name line; option "Rechnungsempfänger auf Dokumenten ausblenden"); Zahlungsbedingungen + Skonto per customer; **X-Rechnung** fields: Leitweg-ID (mandatory for X-Rechnung), Bestellnummer, Lieferantennummer; Umsatzsteuer-ID (printed); **abweichende Debitorennummer**. Address order on invoice: Kundenname → Rechnungsempfänger → Adresszusatz → Adresse. Customer setting takes precedence over an Auftrag's abweichende Rechnungsanschrift. (#742597, #112401)
- Tab **Dokumentation** on customer: all Einsätze with photos; tick-all checkbox → "Bilder herunterladen" → individual JPG files to Downloads (no zip mentioned). Also via right-click. (#267356, #176616)
- Objekt fields: Objektleiter, address (mandatory), Vertrag/Vertragsende, Sonstiges, Materialwesen tab (allowed articles), QR-Code / Kundendashboard buttons top right, Aufträge tab. (#111563, #111807, #355817)
- Object import (#197465): Kundennummer (must match), **Objektnummer numbers only — letters cannot be imported**, Objektname (recommend distinct from customer, e.g. "Büro Frau Müller" or the street), full address (check in Google Maps; used for GPS at stamping), Objektleiternummer (employee number), Beschreibung (**visible to employees on the Einsatz**), Ansprechpartner + phone/e-mail (**NOT visible to employees**).
- Data model implied: Kunde 1→n Objekt 1→n Auftrag 1→n Einsatz(-serie); Kontakt n↔ Kunde/Objekt.

## 4. Aufträge (contracts/orders) (#112401, #111811, #234984, #273957, #742934, #151652)

- Auftrag created from Objekt → Aufträge → "Auftrag erstellen", or from Faktura → Aufträge. Required: Objekt, **Auftragsart**, Nummer, Startdatum (start of service period), optional Enddatum. (#112401)
- **Auftragsart** = type of service (Unterhaltsreinigung, Glasreinigung, Sonderreinigung, Treppenhausreinigung) — PlanD advises keep generic; too specific ones ruin reporting. (#742934)
- Comment on an Auftrag shows on all its Einsätze (all series); attachment on Auftrag shows on all Einsätze. (#742934)
- Angebot → one-click convert to Auftrag (takes over Objekt, Auftragsart, positions). (#111811)
- Auftrag list filter: Manuell / Wiederkehrend / Ohne Abrechnung; Faktura shows "Nicht Abgerechnet". Faktura Auftrag statuses Aktiv / Geplant / Historisch (collection). (#111811, #133740)
- **Stundenkontingent** (hour quota): Auftrag → Auftragseinstellungen → Allgemein → toggle "Stundenkontingent verfügbar" under start/end date; Berechnungsart **einmalig / wöchentlich / monatlich**; hours. Compared live with planned Einsatz hours when creating/editing Einsätze, in the Auftrag view of the planner and in Auswertung. (#234984, #112401)
- **Verrechnungssatz (Beta)**: toggle "Verrechnungssatz verfügbar"; stündlich or Pauschalbetrag; Zielmarge %. Defined as internal average cost/hour/employee incl. wages + variable costs, no profit. (#234984)
- **Auswertung** tab (Faktura → Aufträge → open → Auswertung): Deckung (Beta), Auslastung, Krankheitsquote, which employees stamped, hours current/previous month, number of Einsätze; travel time shown separately from Einsatz hours. (#234984, #747827, #111569)
  - Deckung = Budget × Marge − freigegebene Zeit/Kosten; Budget = Stundenkontingent × Stundenverrechnungssatz. Example 4h × 32 € = 128 €, 30 % → 38,40 €. Deckung **does not** use the invoice amount. (#273957)
  - Auslastung = available Kontingent vs planned hours (target ~100 %). Krankheitsquote = absence days / attendance days with planned Einsätze. (#234984)
- **Kostenstelle** per Auftrag (#151652): free value; recommended = Kunden-/Objekt-/Auftragsnummer. **Standard-Kostenstelle** (Einstellungen → Auftragswesen → Auftrag → Kostenstellen): Kundennummer / Objektnummer / Auftragsnummer / Keine, auto-filled when creating. Auftrag value always overrides standard. Exported in all prefab invoice exports (custom export needs column "Auftrag Kostenstelle"); payroll exports with Kostenstelle column: PlanD Detaillierter Export, Datev, Agenda, Sage, Benutzerdefiniert. Multiple Kostenstellen in one row joined with `|`; option **"Exporte nach Kostenstellen aufteilen?"** splits rows (e.g. 02:00 → 01:00 + 01:00). Limitation: standard Kostenstelle only auto-filled in an export if another column refers to the same entity type (e.g. Kundennummer not fillable in the detailed export). Absences get Kostenstellen only with splitting on: PlanD looks at the Einsätze/Aufträge affected in the absence period and allocates continued pay proportionally (2h + 1h Einsätze, 8h holiday pay → 5.33h / 2.67h). Absence Kostenstellen only for absences submitted after 15.04.2024; standard Kostenstellen not supported for absences.
- Settings → Auftragswesen → Auftragseinstellungen: option "Abweichenden Rechnungsempfänger hinterlegen" (required to see "Abweichende Rechnungsanschrift" field on Auftrag). (#112401)

## 5. Planning [Einsatzplanung / Einsatzplaner] (#742934, #142237, #653765, #526624, #742960)

- Planner is a calendar: one column per employee, Einsätze per day. Week navigation arrows next to "Heute". (#742934)
- **Colour code**: blue = future, no time stamp; red = past, not stamped; green = stamped successfully; **blinking red dot** = employee currently clocked in (real time). Holidays: orange dot (#142373). Recurring: 🔄 icon top right. Vertretung: 🔥 flame. (#742934, #747887)
- Create: click day at employee → choose Objekt (search by name/address/postcode) → Auftrag (or create new) → einmalig or wiederkehrend.
  - Recurring: start/end time (e.g. 07:00–15:00), weekdays, interval (every week, every 3 weeks…), optional end date (none = unlimited). One-off: date, time, employee.
- Drag & drop to other employee/day; dialog asks single vs whole series. Unchecked → single Einsatz leaves series (no 🔄); series continues unchanged next week at old employee. Checked → whole series moved. (#742934)
- **Unassigned Einsätze** [Einsätze ohne Mitarbeiterzuordnung / offene Schicht]: magnifier icon top right → extra column on top; drag to an employee or assign via Quick Actions. (#742934)
- **Team-Einsatz**: mark Einsatz → Quick Actions → add employees. (#742934) ⚠️ When several employees are assigned to one Einsatz, **time is not split** — each gets the full span; adjust manually. (#747887)
- Pin employees ("Männchen" icon) to keep in view; check capacity on day level. (#747887)
- Option "Arbeitsschein anlegen" in the Einsatz creation dialog (needs Leistungen on the Auftrag). (#747838)
- **Routes / Tourenplanung** (#653765): planner → "Routen" button top right → side panel → "Vorlage erstellen": title, description, "+ Einsatzbausteine hinzufügen" (Objekt + Auftragsart, **duration per object mandatory**, optional break and description). Panel shows number of Einsätze and total time. Drag route onto employee+day → dialog asks additional employees and from/to; given a start time, end time auto-computed from total duration; einmalig or wiederkehrend. Planned route editable (remove/add objects, times, employees) — changes affect only that instance, not the template. "Routen anzeigen" toggles bundled vs individual display. App: push "Du hast eine neue Route"; when first Einsatz started the app shows how many stops and how many done; swipe "Weiter zum …" to next stop instead of start/stop each. Absence re-planning: route Einsätze cannot be assigned individually (greyed out) → Massenänderung button **"Route zuweisen"**; choose route then replacement employee; shown with flame. Use cases: Winterdienst, Treppenhaus, Mülltouren.
- **Mobile planning** (Manager-App, #526624, #742960): tab Einsatzplan in employee/object detail — day view, swipe through times/days, tap Einsatz for detail/edit; "+" in Einsatzplan or Suche tab "+" top right to create an Einsatz with all Dashboard fields; detail view; Edit button.

## 6. Time tracking & approval [Zeiterfassung, Zeitenfreigabe] (#111566, #111569, #201054, #201180, #742960)

- **Zeitenfreigabe** = central list of every time stamp that deviates from plan. Reasons: under/over-work outside buffer; location error at clock-in/out; device location permission off; **free time capture (always)**; **times added afterwards (always)**. (#111566)
- Per entry: tick at end of row → **"Sollzeit freigeben"** (planned) or **"Ist-Zeit freigeben"** (actual). Or open entry: planned vs captured, where they clocked in on location error; may enter **own value** (e.g. 11 min instead of 60/65). (#111566)
- Settings (gear icon top right of Zeitenfreigabe):
  - Location: Standortfehler (GPS vs object address), Deaktivierte Standortfreigabe, GPS-Erfassung on/off, **Maximale Toleranz (Meter)** — recommended **300–800 m** and not communicated to staff. Location check needs app location permission.
  - Time: **Unterschreitung (Puffer)** e.g. 10 min auto-approved; **"Automatisch auf Sollzeit aufrunden"** (5 min early → still paid the planned 2h); **Mehrarbeit (Puffer)** — from how many minutes overtime needs manual approval (strict = 1 min).
- Known bug/FAQ: badge shows e.g. 4 but list empty → stale browser cache; clear cache (Ctrl/Cmd+Shift+Del), reload, or other browser. Badge and list not always synced. (#111566)
- **Free time capture [Freie Zeiterfassung]**: app → Kalender → grey stopwatch top right; no planned Einsatz needed; for prep/after-work, short jobs; always lands in Zeitenfreigabe. (#111566) Collection also has "Nachträgliche Zuordnung freier Zeiterfassungen" (assign free captures to Aufträge/Einsätze afterwards). Used for Hausmeister/standby billing (#572389).
- **Added times [nachgetragene Zeiten]**: in app's **Stundenzettel** (e.g. empty battery) → always in Zeitenfreigabe. (#111566)
- **Deviating dates** (#201054): app Kalender (week view, current day highlighted), swipe to past/future week, tap the open shift, start capture and enter times — past or future.
- **Restart Einsatz** after accidental end (#201180): can be restarted up to **12 hours** after ending; tap the Einsatz in the Kalender; previous time kept, new time added; the gap is automatically logged as **Pause**. Don't capture other times in the gap (overlap in payroll).
- Objektleiter app: release Soll/Ist or open full stamp, for stamps from their objects. (#742960)
- **Travel time [Fahrzeit]** (#111569): Einstellungen → Zeiterfassung → Fahrzeit (bottom): toggle; counts only if gap between end of one Einsatz and start of next ≤ **3 h default** (max gap configurable). Must also be enabled per employee: Mitarbeiter → Vertrag → allow Fahrzeiterfassung. Computed automatically as gap end→next start; tip: start next Einsatz only on arrival, otherwise only **1 minute** of travel is recorded. Not in the day hour sum of the planner; shown separately per Einsatz under Mitarbeiter → Lohnzeit; included in payroll evaluation and DATEV exports. Edit: Mitarbeiter → Lohnzeit → Einsatz → pencil under "Freigabe" → travel, break, times. Auftrag Auswertung shows travel separately.
- Photos at Einsatz: app photo documentation; visible at the Einsatz; customer record overview of all Einsätze with photos; bulk download. (#176616, #267356)

## 7. Absences & leave [Abwesenheiten, Urlaub] (#747887, #111571, #111577, #112719, #133744, #133749, #142373)

- Sidebar "Abwesenheiten"; red number = open requests. Calendar view: open requests semi-transparent and dashed. List view top right (shows far-future ones); eye icon hides historic absences. (#747887, #133749)
- List-view tabs: **Alle, Offen, Genehmigt, Zugewiesen, Abgelehnt**. Genehmigt = approved but affected Einsätze not yet re-planned (🟠); Zugewiesen = all affected Einsätze re-planned (🟢). Also status Storniert (filter). (#133749, #747887, #112719)
- Absence types e.g. "Hitzefrei", "Urlaub", "Krank"; custom types via Einstellungen → Abwesenheiten → "Abwesenheitsart erstellen" (flag paid). (#747887, #142373)
- **Payout options [Auszahlungsart]** (5): **Vertragsstunden**, **Planstunden** (planned hours in the period), **Stundendurchschnitt** (Sollzeit daily average of last 3 months), **Unbezahlt**, **Abwesenheitsfortzahlung** (individual daily rate; only selectable if set in profile). (#747887)
- Absence days computed from profile's working days (full-time Mo–Fr: 1 week sick = 5 days; Minijob Mo+Mi: 2 days); days and period manually adjustable. (#747887, #111577)
- "Freigeben" → employee gets **push** of approval; shows total hours (4 days × 8h = 32h) and affected Einsätze. ⚠️ **Re-planning is never automatic** — manual: per Einsatz (→ "Offene Schicht" or a specific employee) or Massenänderung on several; "Zuweisen". Recommendation: assign a person rather than open shift (traceability). Assigned employee gets push. (#747887)
- Original Einsätze stay **greyed out** at the absent person — must not be deleted: used for absence quota on Aufträge, and **auto-rollback**: if the absence is later rejected, Einsätze go back to the original person and Vertretung Einsätze are deleted. (#747887)
- **Vacation entitlement** settings: Einstellungen → Abwesenheiten → Urlaubsanspruch: default days/year (Rahmentarifvertrag Gebäudereinigung = 30), **Wartezeit** for new hires, **Übernahmeregelung / Resturlaub** toggle with how many days carry over and when they expire [verfallen]. (#111571, #133744)
- Calculation (#112719), visible at Mitarbeiter Details → Abwesenheiten (hover Anspruch/Verfügbar/Genommen explains): employee's own entitlement, else company default; + adjustment [Anpassung]; pro-rata by Vertragsstart/-ende (01.02–31.12 → 10/12); with Wartezeit, 1/12 unlocked per completed month. Verfügbar = (Anspruch + Resturlaub) − Genommen; Resturlaub shown only in the year it is active; taken days deducted from Resturlaub first. Only **approved** absences reduce availability; cancelled ones still listed but not counted.
- Weekly working pattern drives leave deduction (3-day week → 3 days per week off). Employee sees remaining entitlement in the app when requesting. (#111577)
- **Only one absence per day** — a holiday inside a vacation must be split into three absences (before / holiday / after). (#142373)
- E-mail absence notifications exist (collection title only).

## 9. Payroll, wage types, surcharges [Lohnabrechnung, Lohnarten, Zuschläge] (#692418, #692398, #747902, #151652)

- **Zuschläge** (Einstellungen → Zuschläge → "Neuer Zuschlag"): Name, Zuschlagshöhe (% on hourly wage), **Aktiv an**, Lohnarten. Types of "Aktiv an": **Wochentage/Uhrzeit** (e.g. Mo–So 22:00–05:00), **Feiertage** (pick from list), **Auftragsarten** (e.g. only Glasreinigung; PSA surcharges), **Belastungszuschlag** (daily/weekly hour threshold exceeded; only on actual, not planned, hours). Computed at every salary creation [Gehaltserstellung]: employee Lohnart → its Zuschläge → time overlap. Overlapping same-category (night + Sunday) → **only highest**; different categories (night + Belastung) combine; multiple Erschwerniszuschläge combine (e.g. Atemschutzmaske + Fassadenreinigung). Locked [gesperrte] salaries unchanged when surcharge edited. Gehaltsliste shows a surcharge icon; hover → name + duration. (#692418)
- **§3b EStG tax-free surcharges**: PlanD knows limits and splits in export: Nacht 20–06 25 %; Nacht 00–04 (shift begun before 0h) 40 %; Sonntag 50 %; Feiertag 125 %; besondere Feiertage (Weihnachten, 1. Mai) 150 %. Example: night 30 % → 25 % tax-free + 5 % taxable. Marked "(stfr.)" in Gehaltsliste, hover, sidebar. Split only if a **tax-free Lohnnummer** set in the **Tarifvorlagen-Wizard**; only for surcharges created from tariff templates, not manual ones. (#692398)
- **Lohnabrechnung** view per employee: Vertragsstunden (weekly → month), planned hours, released hours, surcharges. **Red = not released** → release all, release single ("Vorgabe freigeben"), or open Einsatz to edit time/travel/break. "Zeiten auffüllen" fills Sollzeiten for a selected employee. (#747902)
- ⚠️ Export subset: ticking employees + Exportieren does **not** act as selection; must filter via Mitarbeitergruppe / Anstellungsverhältnis / Tags. (#747902)
- **"Lohnexport erstellen"** formats: DATEV (standard), DATEV Lohn und Gehalt, DATEV LODAS (both need Mandanten- and Beraternummer in Einstellungen → Allgemein → Steuereinstellungen), Edison, Agenda, Sage. Also "PlanD Detaillierter Export" and custom (#151652). DATEV content: Personalnummer/-name, Lohnnummern per Kostenstelle, Stundenlohn, Lohnart, hours, surcharges (tax-free/non-tax-free split), Lohngruppen. (#747902)
- **Lock [sperren]** Lohnzeiten after sending to the payroll office ("zollkonform"); locked cannot be edited. (#747902)
- Collection mentions: Tarifvertrag-Wizard (auto-create Lohnarten from tariff template; chooses right one among several Lohnarten per employee), Mehrere Lohnarten pro Mitarbeiter, Lohnabrechnung als Service (PlanD offers payroll as a service), DATEV Lohn & Gehalt ASCII import.

### Billing on the Auftrag [Rechnungseinstellungen im Auftrag] (#112401, #111811)
- Three Abrechnungsarten: **Keine Abrechnung** (no positions possible), **Manuelle Abrechnung** (positions; invoice created manually with date + service period chosen each time; for one-offs), **Wiederkehrende Abrechnung**: intervals Wöchentlich, Zweiwöchentlich, Monatlich, Vierteljährlich, Halbjährlich, Jährlich. Monthly+ : choose month/day — first, last or custom (e.g. 15th); preview shows next run ("Nächster Rechnungslauf: …"). Service periods from start date (01.01.2024): weekly 01–07.01, biweekly 01–14.01, monthly 01–31.01, quarterly 01.01–30.03 (sic), half-year –30.06, yearly –31.12; weekly/biweekly invoiced the day after period end.
- Creation: **Entwurf erstellen** (draft, editable) or **Fertigstellen** (final, next number, locked). Dispatch for Fertigstellen: **Kein Versand** (under "Offen"), **E-Mail** (customer's invoice recipient + CC), **Post** (via an interface to the customer address).
- Default Rechnungsvorlage per Auftrag. Invoice positions on Auftrag also feed Arbeitsscheine.
- **Ausführungsort** = object address, printed; can't be removed from auto invoices — workarounds: manual invoice (Faktura → Rechnungen → Neue Rechnung, then "Duplizieren" monthly) or delete object from the draft. Not printed twice if object name exactly equals address.
- Rules/quirks: deleted draft reappears next day if (1) a manual invoice was written for that period (not recognised as belonging) or (2) a gap period exists (system fills skipped month first). Fix: move Auftrag start date to first unbilled period + write current month manually. Writing a one-off manual invoice shifts the cycle → use the date of the next automatic run. Changing interval: next cycle aligns to start date/last invoice; no invoice for current month until period complete. **No 0 € invoice**; **only-dynamic / price-less text positions → invoice only if an Einsatz happened**; flat positions → always invoiced. Auto drafts keep the configured invoice date (not the date you finalise).
- c/o address: Kunde → Rechnungswesen → Rechnungsempfänger (replaces name line 1 per one article; another says shown as 2nd line under customer name), Adresszusatz, Auftrag "Abweichende Rechnungsanschrift" (overrides all address fields for that Auftrag; empty one blanks the customer address!).
- Merge drafts of same customer: Faktura → Rechnungen → Entwurf → filter customer → tick → **"Zusammenführen"**; checks Rechnungsdatum, Zahlungsziel, Leistungsempfänger, Rechnungsanschrift; on mismatch a picker. **Drafts only.** (#112401, #572389)

### Dynamic positions [Dynamische Positionen] (#747827, #572389)

## 11. FiBu / DATEV exports (#203506, #133604, #747893, #302527, #757025)

Error sources: accounts, Debitorennummern, Mandanten-/Beraternummer, month-spanning period, double import. ⚠️ **Known defect: Storno numbers exported in Belegfeld 1 but must be in Belegfeld 2 — swap manually in the data sheet.**

## 20. Troubleshooting (#115623, #120069, #180865, #111566, #757025)

- Slow: supports **Chrome or Firefox** at full speed; **Safari/Edge not recommended**. Reload (updates load in background), log out/in, clear cache, other browser, support → "Mit einem Menschen sprechen". **Einsätze are computed locally on the user's computer** → planner speed depends on the PC. Status page status.pland.app, checked every 5 min, normal response ~900 ms.
- Logged out repeatedly: multiple windows/tabs in different browsers, private tab, opening `https://cloud.pland.app/login` in a new tab logs out the other session, **same licence on several laptops in parallel** (implies single session per user licence). Copying another URL doesn't log out.
- Timezone mismatch: PlanD warns when device timezone ≠ system timezone; fix device settings (Mac/Windows steps).
- Zeitenfreigabe badge/list mismatch → cache.
