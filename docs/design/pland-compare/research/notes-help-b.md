- **Erste Schritte mit PlanD** (33 articles), the onboarding curriculum, ordered as lessons:

  - L1: master data and data structure (software basics, employees, data structure, customers, objects).
  - L2: planning, staff app, time tracking, travel time (planning basics/advanced, staff app, the Objektleiter app, approving time records, travel time).

  - L5: invoicing (invoice settings, manual/recurring billing, dynamic positions, work sheets basic/advanced, dunning/credit notes/cancellations).

## 1. Data model & master data (customers, objects, employees, structure)

### Data structure — `742578-die-datenstruktur-in-pland` (27 Jul 2026)
- Hierarchy: **Kunde** (client; quotes & invoices) → **Objekt** (site; planning) → **Auftrag** (concrete service at the site; planning & invoicing) → **Einsatz** (time-scheduled occurrence; planning).
- Customers: left sidebar "Objekte" → expand arrow → "Kunden". Record: name, address (+suffix), Rechnungswesen (invoice recipient); second tab "Objekte". Object shows its Aufträge. Auftrag holds billing positions and Einsätze. Einsatz = days, times, employees. Plan via Auftrag or via Einsatzplaner (Objekt → Auftrag → Einsatz).

### Objects (Objekte) — `742933-objekte-in-pland` (27 Jul 2026)
- Objects = buildings/sites; object name shows in planner when creating an Einsatz and is the first thing an employee sees in app time tracking. Left sidebar "Objekte" list.
- Fields: name & address (visible in app); Leistungsempfänger (separate service recipient — printed on invoice); contact info (recommend separate Kontakte linkable to customer, several objects, shown in app).
- Vertragsdaten: start/end. ⚠️ **Setting a contract end moves all related Aufträge and Einsätze to that end date automatically.**
- "Sonstiges" (visible in app): key data & access codes, object description (entrance, material room); Objekt-Tags for planner filtering (tours, localities, postcodes).
- Dokumente tab (service specifications/Leistungsverzeichnisse, site plans, safety rules); visibility "Alle" (all employees with an Einsatz on this object + dashboard users) or "Nur Dashboard-Nutzer" (Objektleiter, Innendienst, Admins).
- **One Objektleiter per object**; gets push in app on changes (absences of employees with Einsätze there, new tasks, material orders for object). Assign in bulk: tick objects → Quick Actions → set Objektleiter.

### Employees (Mitarbeiter) — `111562-mitarbeiter-in-pland` (27 Jul 2026)
- Dashboard → Mitarbeiterübersicht (list of all employee master data); blue button "Mitarbeiter erstellen" top right. Lists support column customisation and mass changes via Quick Actions.
- Basic data: first/last name, language (Sprache), address, email, phone. **Phone number is the key for the app invitation** (invite goes by SMS to that number).
- Contract data (Vertragsdaten):
  - Employment type (Anstellungsart) drives availability calc in planner: **Geringfügige Beschäftigung (Minijob)** → availability = Minijob salary limit ÷ gross hourly wage, automatic; **Vollzeit/Teilzeit** → based on weekly hours.
  - Employee groups (Mitarbeitergruppen): pick or type a new one; a group is **automatically deleted when no employee is assigned anymore**.
  - Contract start (Vertragsstart): leave entitlement pro-rated automatically. Contract end (Vertragsende): employee automatically set to "Passiv"; system asks whether existing jobs (Einsätze) are updated — future Einsätze removed or kept for later re-planning.
  - Pay data (Lohndaten): wage (Lohn) vs salary (Gehalt) + pay type (Lohnart). ⚠️ "Currently ALL dashboard users can see pay data" — PlanD recommends not entering sensitive pay data during onboarding, restrict later via custom permission groups.
  - Weekly hours (Wochenstunden): used for planner availability and for continued pay (Entgeltfortzahlung) on sickness/leave/other absences.
- Account: employee number (Mitarbeiternummer) — should match payroll system; **must be numeric and unique**. Status: Aktiv / Interessent (prospect) / Passiv.
- Permission groups (Rechtegruppen) default four: Admin = full access; Innendienst = planning & invoicing (Faktura); Objektleiter = planning only; Servicekraft = app only. Custom groups possible.
- Tags: used to filter employees in planner (company affiliation, substitute role, holiday pay, driving licence/truck licence, special training/qualifications).
- Sonstiges: free comments. Documents (Dokumente): upload per employee (contracts, payslips) with visibility: "Dashboard-Nutzer" (Objektleiter, Innendienst, Admins only) or "Alle" (also employee in app + all dashboard users). Warning: upload sensitive docs only after permission groups set up.
- Invite: open employee record → "Zugangsdaten senden" → SMS to stored phone.
- FAQ: No SMS → employee can log in in app via "Mit Handynummer einloggen" with the stored phone number; or send credentials to yourself and forward manually.
- FAQ: **Employees with group "Admin" cannot receive credentials** — workaround: temporarily assign a lower group (Innendienst/Objektleiter/Servicekraft), send credentials, then set back to Admin (prevents accidental full-access invitations).

### Employee groups — `180082-mitarbeitergruppen-erstellen-bearbeiten-und-loschen` (25 Feb 2026)
- Groups are free-text: type into group field → "Hinzufügen" → available for all employees. To change: delete existing with delete key, type new, Hinzufügen. Dynamic: group disappears from selection when no employee has it (cleanup mechanism). Filter for planning, exports, reports.

### Mass changes — `234488-massenanderungen-in-listen` (30 Oct 2024)
- Employee/object/customer/contact lists: tick records → "Massenänderungen" → choose field (e.g. Status, Tags; customer A/B/C category) → new value → save.

### Custom fields (Eigene Felder) — `324192-eigene-felder-in-pland` (6 Jun 2025)
- Internal capture only: NOT shown on documents, NOT in payroll export, no automatic linking (e.g. devices to Einsätze). Can be shown as list columns, filtered, sorted, exported.
- Examples: employee/customer: licence yes/no (dropdown), licence valid until (date picker), residence permit valid until, IBAN/BIC (text field). Auftrag: multiselect dropdown of billing months (Jan–Dec) for seasonal jobs (winter service, garden).
- **Limit: up to three custom fields per company** ("to keep the system tidy").

### Custom fields (detailed) — `747849-eigene-felder` (29 Jul 2026)
- Einstellungen → Allgemein → Eigene Felder → "Benutzerdefiniertes Feld erstellen": Bezeichnung, Beschreibung (help), Datensatz (record type: Mitarbeiter, Kunde, Objekt, Bestellung, Gerät "u. v. m.").
- Options: Pflichtfeld (required — cannot save if empty), In der App anzeigen (Objektleiter-App under "Suchen"), Im Erstellungsformular abfragen.
- Types: Textfeld, Mehrzeiliges Textfeld, Zahl, Datumsauswahl, Dropdown (single), Mehrfachauswahl, Checkbox.
- Columns ("Spalten"), filters ("+ Filter hinzufügen": ist gleich / größer als / kleiner als / gesetzt / nicht gesetzt) e.g. licence expiry < 31.05. No linking between records. (Earlier article 324192 says max 3 custom fields per company.)

### Comments — `133742-kommentare-auf-objekt-auftrag-und-einsatz` (7 Aug 2024)
- Objekt → Sonstiges → comment field (shown to all employees with Einsätze there). Auftrag (via Objekt → Aufträge) comment field (for all employees on that Auftrag). Single Einsatz: click in planner → comment field; hover in planner shows it. Works for recurring too.


## 2. Planning — Aufträge / Einsätze / planner (Einsatzplaner)

### Jobs & scheduling (Aufträge/Einsätze) — `111564-auftrage-und-einsatzplanung-in-pland` (25 Feb 2026)
- Duty roster (Dienstplan) in dashboard = calendar; Day ↔ Week toggle top right; date picker top left. Blue "Einsatz erstellen" button. Filter next to search: employee groups, objects, plus filters like object experience (Objekterfahrung — has worked at that site before) and job types (Auftragsarten — e.g. has done Unterhaltsreinigung before).
- Magnifier icon top right: shows all unassigned Einsätze (unbesetzte Einsätze) → drag & drop onto a free employee. Eye icon: expand all Einsätze (multiple per day stacked).
- Colours: green = completed, red = not completed, blue = future. Small icons top-right of an Einsatz: team job and recurring. Grey areas = days employee not available; click an employee to set which days/how many hours he works — only those days are open for assignment.
- Bar under each employee name: hover shows planned vs remaining available hours for rest of week and month; turns red when exceeded.
- One-off Einsatz: in Einsatzplaner drag-select the time → choose Objekt and Auftrag (or create new Auftrag e.g. Glasreinigung/Unterhaltsreinigung; job types configurable in Settings). Aufträge can only be **archived** in settings when no longer relevant. Choose einmalig/wiederholend, date & time, comment, attach document (e.g. access code). Bottom left: notify employee immediately. Einsätze can be dragged and reassigned.
- Recurring: in week view click employee → Objekt + Auftragsart → "Wiederholend" → interval (weekly, every two weeks on Tuesday, monthly).
- Changing a recurring Einsatz by drag & drop → PlanD asks (checkbox) whether change applies to all following dates or only this one. Same choice when editing inside. **Changes to series only affect the future; individually detached Einsätze are no longer affected by series changes.**
- Team Einsätze (Teameinsätze): open Einsatz → Mitarbeiter → Hinzufügen; for recurring, all instances appear for added members. Deleting asks: apply to following dates? apply to other members?
- Daily availability (Verfügbarkeiten auf Tagesebene): number top right of each day in decimal hours (8.0, 4.5, 7.25). Grey number = free capacity; red minus = overplanned; green tick = exactly planned; no display = no weekly hours on profile. Based solely on weekly hours in profile.

### Advanced planning — `742935-einsatzplanung-fur-fortgeschrittene` (27 Jul 2026)
- Standard filters: employee group (e.g. Springer/floaters), object. "Filter hinzufügen": Objekterfahrung.
- Mass move: hover Einsatz → tick checkbox bottom right → select many → drag together to employee/day.
- Tours (Touren): "Touren" top right → name (e.g. "Schaufenster Innenstadt") → add objects + their Aufträge → set duration per Einsatz → assign to employee with only start time; end auto-computed from durations. Recurring possible. "Tour optimieren" → map with stops → reorders for best/shortest route. Edit route container in planner: reorder, add employees.
- Views (top right): Mitarbeiteransicht (default), Objektansicht (objects left), Auftragsansicht (per Auftrag). Object view: search by address, filter by postcode.

### Employee vs object view — `140378-die-mitarbeiter-und-objektansicht` (6 Aug 2024)
- Toggle button top right of Einsatzplaner: employee view ↔ object view. Object view has no magnifier; unassigned Einsätze marked inline per object. Group Einsätze labelled "Team Einsatz"; hover group icon shows assigned employees.

### Planner filters — `142239-die-filter` (6 Aug 2024)
- Combine any number of filters. Employee view: Mitarbeitergruppen (set at Mitarbeiter > Informationen > Vertrag); Arbeitet im Objekt (actively planned there); Objekterfahrung (ever assigned to an Einsatz there, incl. substitutions/old one-offs); Mitarbeiter Tags (set at Mitarbeiter > Informationen > Account); Aktiv am Arbeiten (currently working).
- Object view: Objekt Tags (Objekte > Informationen > Sonstiges); Kunden.
- Both: Auftragsarten; Objektleiter (objects assigned to that site lead; multiple responsibles → use object tags); Objekte und Mitarbeiter (any selection).

### Duplicate Auftrag — `234986-auftrage-duplizieren` (30 Oct 2024)

### Travel-time problems — `133753-probleme-bei-der-fahrzeiterfassung` (6 Aug 2024)
- Travel time recording works even with GPS off, offline, and with free time tracking; only the gap between Einsätze counts: one Einsatz completed + new time tracking started. **Travel time to the first Einsatz of the day cannot be recorded via the app.**

- Radius ~**500 m** around object address without error. Causes: approximate location on poor connection; imprecise address (compare with Google Maps; re-enter address); no internet → no location → time goes to approval; GPS timeout → "Deaktivierte Standortfreigabe"; old phones. App can be used offline without location.

### Wage types & surcharges (basic) — `111570-lohnarten-und-zuschlage-in-pland` (25 Feb 2026)

### Wage types & surcharges (full) — `747896-lohnarten-und-zuschlage`
- Einstellungen → tab "Lohn": Abrechnungstag (usually 31st), Nachtarbeit window (e.g. 20–6), Land & Region (determines statutory public holidays).

- Other: PSA (PPE, levels), special works (Sheddachreinigung, Grundreinigung ÖPNV) — **only created if linked to an Auftragsart**; Belastungszuschlag >8 h/day or >40 h/week 25% (custom thresholds via manual creation).
- Mapping: deactivate irrelevant per group; link hardship/euro-based surcharges to groups and job types. LG1 doing Glas → LG6; LG6 doing Unterhalt stays LG6. Preview → existing surcharges overwritten not duplicated → "Fertigstellen".
- Own wage types must be manually added inside each surcharge, else surcharges don't apply.
- Deviating wage type per job type: Einstellungen → Auftragswesen → Auftragsarten.
- Employee: Mitarbeiter → tab "Vertrag" → "Vergütung" → Lohnart (e.g. Stundenlohn LG 1).
- Check: Mitarbeiter → "Lohnzeit" → hover icon after an Einsatz shows surcharges (e.g. "steuerfrei: 4 Std. 30 Min."); monthly summary at bottom. "steuerfrei" icon only means a tax-free share exists; exact split in export.

### Wage types & surcharges (cont.) — `747896-lohnarten-und-zuschlage`
- Diagnosis "surcharge not in pay time": (1) Lohnart in employee profile (Vertrag → Vergütung); (2) Lohnart linked in the surcharge (Einstellungen → Lohn → Zuschläge → open surcharge → its Lohnarten list); (3) job type with deviating wage type — surcharge must be linked to that one too; (4) **surcharges are computed at the moment of approval** — times approved before the link are not recalculated; re-open and re-approve each stamp. Locked (exported) pay times cannot be re-approved.

### Collective-agreement wizard (Tarifvertrag-Wizard) — `692392-tarifvertrag-wizard` (2 Jun 2026)
- Einstellungen → Lohnarten → "Tarifvorlage anwenden". ### Multiple wage types per employee — `692401-mehrere-lohnarten-pro-mitarbeiter` (2 Jun 2026)

### Burden surcharge (Belastungszuschlag) — `692420-belastungszuschlag` (2 Jun 2026)

- Stock: filter "Mindestbestand unterschritten". Stock is **central warehouse only, not per object**.
- Material cabinets: Option A article as "Standard" (orderable on all objects); Option B object → tab "Materialwesen" → add articles + budget. Budget = max quantity per employee per 30 days on that object; 0 = unlimited. (Note: older article 133746 calls budget an approximate value.)

- Delivery note PDF: logo, billing address (customer), delivery address (object), company data, contact = phone of approving employee, VAT id, order date, extra fields, supplier, items. ⚠️ **Cannot be signed in the app** — print and sign manually.
- Billing: sale price under Rechnungswesen → Produkte (e.g. €3.00). Single: open completed order → "Rechnung erstellen". Multiple same customer: tick → "Abrechnen" → one invoice; moved to "Abgerechnet"; invoice shows "Verknüpfte Bestellungen".

## 14. Cross-cutting findings

### 14.1 Data model revealed

**Core hierarchy and master data**
- Hierarchy: **Kunde → Objekt → Auftrag → Einsatz** (742578).
  - The Auftrag is the billing unit (positions, Rechnungsstellung, cost centre, Lohnart override checkbox, custom fields, Dokumente tab).
  - The Einsatz is the scheduled occurrence that time tracking attaches to.
  - Aufträge carry a temporal status: Aktiv / Geplant / Historisch.
- Customer: name, address, Rechnungswesen (invoice recipient + CC addresses, contact for auto-email, payment terms/Skonto, deviating debtor number), tab Objekte.
- Object:
  - Name, address, Leistungsempfänger, contacts (Kontakte are separate entities linkable to a customer and several objects).
  - Contract start/end, Sonstiges (access codes, description, tags), Dokumente with visibility, **one Objektleiter**, a QR code.
  - Tabs Materialwesen (cabinet) and Schlüssel.
- Employee:
  - Basic data, Vertrag (Anstellungsart Minijob/Voll-/Teilzeit, group, contract start/end, Lohn/Gehalt, Lohnart under "Vergütung", weekly hours, travel-time checkbox).
  - Account (numeric unique Mitarbeiternummer, status Aktiv/Interessent/Passiv, Rechtegruppe, tags), Sonstiges, Dokumente with visibility, Lohnzeit tab.
  - Per-day availability: days and hours.

**Time, pay and absences**
- Pay-time stamps (Lohnstempel): approved times, breaks, travel; an editor/approver audit trail; can be locked (yellow, immutable, Logbuch entry).
- Surcharges are computed at approval time and are not recomputed retroactively. The exception is the Belastungszuschlag, which is recomputed on any weekly change.
- Absence: employee, type, period, day count (overridable), pay basis (Vertragsstunden/Planstunden/Stundendurchschnitt, frozen at creation), affected Einsätze. **At most one absence per day.**
- Absence type: pay number, self-requestable flag, reduces-entitlement flag.

**Wage types**
- Lohnart: name, number, hourly wage, optional tariff template binding ("Vorlage").
- A surcharge links to Lohnarten and Auftragsarten. Time surcharges carry two pay numbers (taxable and tax-free).
- Auftragsart can carry a Lohnart; the higher one wins.

**Tasks, materials and keys**
- Task:
  - Fields: title, type, priority, due date, one assignee, description, attachment.
  - Contact person (email triggers a completion email). Links to employees/Aufträge/Rechnungen/Geräte.
  - Statuses include Neu, In Prüfung, Abgeschlossen, plus Archiviert.
- Material:
  - Article: photo, name, unit, supplier, external number, stock (central only), min stock, description.
  - Cabinet per object with a budget per 30 days.
  - Orders move Offen → Erledigt → Abgerechnet; delivery note PDF.
- Key: title, auto number, engraved ID, description, object, one current holder, comment, attachment.

**Invoicing**
- Invoice statuses: Entwurf → Offen → Überfällig → Gemahnt → Bezahlt / Storniert. Invoices carry a send status and an activity log.
- Work sheets (Arbeitsscheine): Entwürfe / Offen / Überfällig / Erledigt, can be set to "fakturiert". Contents: remark, materials, appointments, photos, customer signature, no prices.
- Payment record: reason Skonto / Teilzahlung. Bank transactions: linked / unlinked / Ignoriert.

**Other**
- Custom fields:
  - Record types: Mitarbeiter, Kunde, Objekt, Bestellung, Gerät, Auftrag.
  - Types: text, multiline, number, date, dropdown, multiselect, checkbox.
  - Options: required, show in app, ask on create.
- Permission group: dashboard access, Objektleiter filter, settings access, master-data export, access level 1–10, pay-data and employee-document visibility, app type, chat create rights, and a per-feature Lesen/Erstellen/Updaten/Löschen/In Navigation anzeigen matrix.

### 14.2 Explicitly NOT supported / limits

**Mobile app and staff**
- Employees with group Admin cannot be sent credentials; the workaround is to downgrade temporarily (111562).
- All dashboard users see pay data unless custom groups are set up (111562). Admin, Innendienst and Objektleiter see employee documents by default (747843).
- The four standard permission groups cannot be edited (171868).
- Staff cannot delete absences, only withdraw future ones (111578).
- No travel time for the first Einsatz of the day via the app (133753).
- Offline mode excludes material orders, absences and tickets. Einsätze must be downloaded beforehand (201179).
- Free GPS time tracking needs a 600 m radius plus one prior normal Einsatz at the object (136369). The approval GPS tolerance is about 500 m (143961).
- Servicekräfte cannot see keys (747579).
- Users without dashboard access see "create" in the Manager-App but cannot save (211767).

**Planning, tasks and materials**
- A duplicated Auftrag does not copy planned Einsätze (234986).
- Setting an object's contract end cascades to all its Aufträge/Einsätze (742933).
- Tasks have no time tracking. A Servicekraft can only set "In Prüfung" (747553).
- Delivery notes cannot be signed in the app (747562). Stock is central, not per object (747562).

**Payroll and pay times**
- Surcharges are not applied retroactively after approval: re-approve, which is impossible once locked (111570, 747896).
- Locked pay times are immutable even for admins (133737).
- Tariff-bound hourly wages cannot be edited; above-tariff pay needs own wage types (692392, 747896).
- Payroll export has no per-day absence dates. Contract hours appear only in the Saldo export (203426).
- Exports over 60 s time out ("Maximum execution time of 60 seconds exceeded"); use "Export per E-Mail senden" (203426).
- The DATEV L&G import needs manual CSV editing for extra columns such as cost centres (342213).

**Invoicing and payments**
- Recurring Aufträge must start on the 1st of the month (747823).
- Dunning templates allow no individual salutation. There is no separate dunning email address per customer (149924).
- Own SMTP is an Enterprise feature, and with SMTP the delivery status is unreliable (115097).
- Bank link (112505):
  - Only German and Austrian banks, on request.
  - One account per environment.
  - Must be enabled by support; admin only.
  - All accounts behind one bank login get pulled.
- CAMT import supports only 5 listed versions (460914).
- Payment date must be after the invoice date for matching (273972). Automatic Skonto recognition needs an exact amount and date (273972).
- Postal letterhead margins are strict: protected_stamp_area / protected_border_area error (112655).

**Paula, custom fields and other**
- Paula phone assistant: German only, inbound only, creates tasks only — no booking, no billing, no write-back (661994).
- Paula assistant: per-user licence with a monthly quota; uploads up to 10 MB; changes only via Confirm Action (756713).
- API: 180 requests/min per key; a key is shown once (364041).
- Custom fields: max 3 per company (324192, 2025). They cannot link records, do not appear on documents and are not in the payroll export (324192, 747849).
- PlanD's own billing portal is English only (534048).

### 14.3 Workarounds / manual steps documented

**Staff accounts and absences**
- No SMS received: use "Mit Handynummer einloggen", or send the credentials to yourself and forward them.
- Absences after a weekly-hours change: toggle Planstunden → save → Vertragsstunden → save.
- Holiday inside a vacation: split into 3 absences.

**Payroll and surcharges**
- Wrong pay lock: correct in the tax adviser's payroll program.
- Missing surcharge: re-approve each time stamp.
- Dated absence list for the tax adviser: absence list view → print/PDF from the browser.

**Imports, exports and payments**
- Excel shows numbers as dates: import via Power Query.
- DATEV L&G: one-time ASCII-Import-Assistent setup, format "PlanD", select "Alle Dateitypen".
- Skonto not recognised: delete the payment and re-enter it with reason "Skonto".
- Bank sync error: disconnect and reconnect.

**Work sheets and invoice emails**
- Actual times not on the Arbeitsschein: write them in the remark, edit positions manually, or create work sheets from Soll-hours via Aufträge mass change (lands in Entwürfe).
- Customer portal rejects invoice emails: whitelist @mail.pland.app or set up own SMTP.
