# Screenshot Guide for Store Listings

## Required Screenshots

### Google Play
- **Phone:** Min 2, max 8 screenshots (1080x1920 or 1920x1080)
- **Tablet 7":** Min 1 screenshot (optional but recommended)
- **Tablet 10":** Min 1 screenshot (optional but recommended)
- **Feature Graphic:** 1024x500 (required)

### App Store
- **iPhone 6.7":** Min 3 screenshots (1290x2796)
- **iPhone 6.5":** Min 3 screenshots (1242x2688)  
- **iPad 12.9":** Min 3 screenshots (2048x2732)

---

## Recommended Screenshots to Take

Take these on both a phone (dark + light mode) and tablet:

### Screenshot 1: Home Dashboard
- Show the hybrid home screen with attendance card + task stats + calendar
- Best in dark mode for dramatic effect

### Screenshot 2: Task List
- Show the tasks tab with several tasks in different statuses
- Include the search bar and filter chips

### Screenshot 3: Task Detail
- Show a task detail with the progress card, assignment info, and route map
- Include the status action buttons

### Screenshot 4: Create Task
- Show the create task form with priority selection and location picker

### Screenshot 5: Attendance / Clock In
- Show the clock-in/clock-out screen with shift timer and break options

### Screenshot 6: Profile
- Show the profile screen with badges, settings menu items
- Best in light mode

### Screenshot 7: Live Map (Web)
- Show the dispatcher's live map with technician markers

### Screenshot 8: Service Report
- Show a completed task with service report, photos, and signatures

## Feature Graphic (1024x500)

Create a banner image with:
- HBCField logo on the left
- Tagline: "Field Operations, Orchestrated."
- Phone mockup showing the app on the right
- Brand color background (#2563EB gradient to #1D4ED8)
- Clean, professional look

**Tools to create:**
- Canva (free): https://www.canva.com
- Figma (free): https://www.figma.com
- Use phone mockup templates

## How to Take Screenshots

### On Android Device:
```
Power + Volume Down (simultaneously)
```

### On iOS Device:
```
Power + Volume Up (simultaneously)
```

### From Expo:
```bash
# Run on a specific device/emulator
cd apps/mobile && npx expo start
# Then take screenshot from device
```

### Tips:
- Use real data (not "test" or "lorem ipsum")
- Clean notification bar (full battery, good signal)
- Use the German language for DE listing screenshots
- Time should show a realistic time (e.g., 10:30 AM)
- Fill the app with realistic task names and technician names
